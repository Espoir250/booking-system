# Doctor Appointment Booking System

This is a multi-page frontend starter built with separate files such as `index.html`, `login.html`, and dedicated dashboards for each role.

## Included Features

- Patient, doctor, and admin role pages
- Search doctors by specialization, clinic, and location
- View doctor profiles and weekly availability
- Book appointments with double-booking prevention
- Cancel and reschedule from the patient dashboard
- Doctor approval/rejection and availability management
- Admin dashboard with users, clinics, and appointment stats

## How To Use

1. Open [index.html](C:\Users\Espoir\Documents\New project\index.html) in a browser.
2. Use the demo accounts from `login.html` or register new users.
3. Test the booking flow across the role dashboards.
